checked on 2026-10-15. Theme and version are `schema_name` and `schema_version`;
they describe the theme, not the Liquid engine (whose version is not exposed).

`theme_store_id` (`null` means not exposed). All observed themes have role
`main`. Each source link points to one example; all saved pages for each
retailer reported the same metadata. These are snapshot observations, not live
storefront checks.
